SOURCE

The JavaScript reads attacker-controlled data from the browser URL:

if (document.location.href.indexOf("default=") >= 0) {

        document.location.href.indexOf("default=")+8
    );

SOURCE IDENTIFICATION:
document.location.href

The URL parameter being processed is:
default=Spanish


DATA FLOW
---------

        ↓

        ↓
lang
        ↓
document.write(...)


SINK
----
The extracted value is written directly into the HTML DOM:

document.write("<option value='" + lang + "'>" + decodeURI(lang) + "</option>");

SINK IDENTIFICATION:
document.write()


RENDERING CONTEXT
-----------------
The value is inserted into an HTML <option> element:

<option value='" + lang + "'>" + decodeURI(lang) + "</option>

The value is therefore being inserted into an HTML/attribute context
through document.write().

FINDING
-------
The client-side JavaScript obtains data from document.location.href and
passes the extracted value to document.write() without context-appropriate
encoding. This establishes a source-to-sink DOM XSS data flow.
